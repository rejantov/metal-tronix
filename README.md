# Metal Tronix Website

## About This Project

This is a website I built for my dad’s business. Unlike some of my earlier projects, this one was meant to be actually used, so I focused more on structure, clarity, and making something reliable.

It’s built using a modern frontend stack, and it represents a step forward in how I approach development compared to my older work.

---

## What Is This Website?

This project is a business website designed to present my dad’s work in a clear and accessible way.

The goal of the site is to:

* Show what the business does
* Provide information about services
* Make it easy for potential clients to get in contact
* Keep everything simple and straightforward to navigate

---

## Technologies Used

* React
* TypeScript
* Tailwind CSS

The entire project is built using a component-based approach, with styling handled through Tailwind. There is no traditional static HTML/CSS structure — everything is handled within the React ecosystem.

---

## Project Structure

The application is structured around reusable components, making it easier to maintain and expand.

Key ideas behind the structure:

* Component-based UI
* Separation of concerns
* Clean and readable layout
* Scalable setup for future updates
